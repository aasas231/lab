About this CW3 SurVis browser

This public SurVis literature browser supports the COMP4126 Coursework 3 review by Tianshu Zhu (20806817). It contains the 18 reviewed papers, verified DOI links, year metadata, paper categories, and evidence tags used in the report.

The page loads the official SurVis frontend from the SurVis GitHub repository and uses locally hosted CW3 bibliography data.
